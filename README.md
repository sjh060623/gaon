# 사이 · 가온

최대 4명의 실제 자동차·대중교통 이동시간을 비교하는 Next.js 웹앱입니다.
출발지는 현재 위치, 주소, 장소 이름으로 검색합니다. 대중교통에는 도보와 환승을 포함합니다.

## 실행

Node.js 22 이상에서 `npm install` 후 `.env.example`을 `.env.local`로 복사해 서버용 키를 입력합니다.
`npm run dev`로 실행하고 `npm test`, `npm run build`로 검증합니다.

## Vercel 배포

GitHub 저장소를 가져오고 Framework를 Next.js로 선택합니다. 다음 값을 프로젝트 환경변수로 등록합니다.

- `KAKAO_REST_API_KEY`: 장소 검색 및 대중교통
- `NAVER_MAPS_CLIENT_ID`: 주소 검색 및 자동차 길찾기
- `NAVER_MAPS_CLIENT_SECRET`: 네이버 인증
- `KAKAO_MOBILITY_REST_API_KEY`: 선택 사항, 네이버 자동차 길찾기 미설정 시 대체

실제 키는 소스에 포함하지 않습니다. 배포 후 `/api/status`로 연결 상태를 확인할 수 있습니다.

## 계산 범위

서울·경기 지역의 주변 후보 역 최대 3곳에 대해 실제 출발지부터 소요시간을 조회합니다.
전 지역의 모든 장소를 전수 비교하는 최적해는 아니며, 교통 상황과 제공자의 경로에 따라 결과가 달라집니다.
자동차 주차 후 도보는 포함하지 않습니다. 선택한 출발지는 서버에 별도 저장하지 않으며 공유 링크에는 출발지가 포함됩니다.
